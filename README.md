📱 TERMUX INSTALLATION

1️⃣ Update Termux

pkg update -y

2️⃣ Install Git

pkg install git -y

3️⃣ Install Python

pkg install python -y

4️⃣ Download GHOST

git clone https://github.com/darkfourty7-cyberwarrior/GHOST-.git

5️⃣ Enter GHOST

cd GHOST-

6️⃣ Check Python

python --version

7️⃣ Start GHOST

python ghost.py

«If your Python file has a different filename, replace "ghost.py" with the actual filename.»
