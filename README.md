👻 GHOST SECURITY CONSOLE

DARK 47

GHOST Security Console v3.0 is a Python-based defensive and authorized security assessment toolkit designed for security research, learning, and systems you own or have explicit permission to assess.

⚡ Features

- 🔎 DNS information
- 🌐 Web security header audit
- 🔐 TLS / certificate audit
- 🔌 Common TCP port scanner
- 🛡️ Security risk analysis
- 📄 JSON security reports
- 🌐 HTML security reports
- 🖥️ Local network information
- 🎨 Dark terminal interface
- ⚡ Multi-threaded port checking

📱 Termux Installation

1️⃣ Update Termux

pkg update -y

2️⃣ Install Git

pkg install git -y

3️⃣ Install Python

pkg install python -y

4️⃣ Download GHOST

git clone https://github.com/darkfourty7-cyberwarrior/GHOST-.git

5️⃣ Enter the GHOST directory

cd GHOST-

6️⃣ Check Python

python --version

7️⃣ Run GHOST

If the Python file is named "ghost.py":

python ghost.py

If your Python file has a different filename, replace "ghost.py" with the actual filename.

---

🖥️ Usage

After starting GHOST, the main menu provides:

1. Full Authorized Security Scan
2. Port & Service Scanner
3. Web Security Audit
4. TLS / Certificate Audit
5. DNS Information
6. Local Network Information
7. Security Risk Analysis
8. Generate Current Reports
0. Exit

Enter the number of the feature you want to use.

---

📄 Reports

GHOST can generate:

ghost_security_report.json

and:

ghost_security_report.html

The reports contain information from the selected authorized security assessment.
