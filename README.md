📲 Installation

1️⃣ Update Termux

pkg update -y

2️⃣ Install Git

pkg install git -y

3️⃣ Install Python

pkg install python -y

4️⃣ Clone GHOST

git clone https://github.com/darkfourty7-cyberwarrior/GHOST-.git

5️⃣ Enter the folder

cd GHOST-

6️⃣ Check Python

python --version

7️⃣ Run the program

python 'Dark GHOST.PY'
