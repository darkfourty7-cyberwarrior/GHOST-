📱 TERMUX INSTALLATION

1️⃣ Update Termux

pkg update -y

2️⃣ Install Git

pkg install git -y

3️⃣ Install Python

pkg install python -y

4️⃣ Download GHOST

git clone https://github.com/darkfourty7-cyberwarrior/GHOST-.git

5️⃣ Enter the GHOST folder

cd GHOST-

6️⃣ Check Python

python --version

7️⃣ Start GHOST

python ghost.py

«Replace "ghost.py" with the actual Python filename if your file has a different name.»
